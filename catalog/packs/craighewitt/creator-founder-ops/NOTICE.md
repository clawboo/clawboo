**Modifications**: this pack is adapted, not verbatim. The upstream repository
ships seventy-four Markdown documents across six folders. Two of those folders
were not imported at all: the coding folder, whose two skills duplicate ground
the Clawboo catalog already covers several times over, and the general folder,
whose two skills are about handing work between assistants rather than about
running a business. The material this pack was built from is the sixty-two skill
documents in the other four folders, fifteen on video, twenty-one on sales, ten
on running a company and sixteen on day-to-day office work, together with the
two context templates and the reference notes that sit alongside them. Nothing
that is not Markdown was imported: two shell scripts, a Python file, two
JavaScript modules, a stylesheet and seventeen evaluation fixtures were all left
behind, because a Clawboo pack carries Markdown and JSON only.

The upstream documents are long interactive scripts, averaging roughly twelve
kilobytes, each opening with an operator persona and a check for a project
context file. That framing was deliberately preserved, because it is the most
useful thing about the originals: every agent here opens as a practitioner and
every agent checks for the shared context document before it advises anything.
Everything else was rewritten. Sixty-two separate documents were consolidated
into fourteen Clawboo agents with the SOUL, IDENTITY and TOOLS document set, so
no agent is a transcription of any single upstream file, and the connective
reasoning that the step-by-step originals leave implicit was written out.

Material bound to specific commercial products was removed rather than
generalised. That includes named contact-data and prospecting services, a named
professional-network sales product, named customer relationship platforms, a
named email provider, named payment processors and a named presentation
framework. Where a technique depended on one of those, the technique is now
described generically so the agents work with whatever tooling a user already
has. Unsourced performance figures, revenue bands attached to management stages
and named third-party sales methodologies were dropped rather than restated. The
four teams, their rosters, the leader choices, the workflow narratives and every
routing edge were written by the Clawboo maintainers, as were the skill
assignments, categories, tags, colours and emoji.
