**Modifications**: this pack is adapted, not verbatim. The upstream ships nine
skill directories plus a template. Two were dropped outright: the one built
entirely around a paid third-party bulk-editing application, and the
landing-page ideation unit, which lands in a cell the Clawboo catalog already
covers. The remaining seven were reorganised into five agents whose scopes do
not follow the upstream directory boundaries. Every reference to that paid
application was removed rather than reworded, and no link to it survives
anywhere in this pack. Store authentication instructions, access-token and
command-line setup, plugin installation commands, pinned API version numbers,
GraphQL query and mutation text, and every request or verification snippet were
removed; what was kept is the method, written as prose. A named brand used
upstream as a worked landing-page example is not named here, and the redirect
worked example is described without the client it came from. Every body was
rewritten from scratch into the Clawboo SOUL, IDENTITY and TOOLS document set,
frontmatter was replaced with structured catalog fields, and every description
was newly written. The team, its roster, the leader choice, the workflow
narrative and every routing edge are original Clawboo work; the upstream has no
team concept. Skill declarations, categories, tags, colours and emoji are
Clawboo's.
