**Modifications**: this pack is adapted, not verbatim. The upstream ships ten
skill directories. The API integration unit was dropped entirely, along with its
endpoint list, authentication steps, model pricing table, polling and webhook
guidance, and code examples. The remaining units were reduced to the
vendor-neutral craft they teach and reorganised into two agents. Every model
name, product name, model-selection table, request field name, request-mode
identifier, parameter and documentation link was removed rather than reworded,
so nothing in this pack instructs anyone to use a particular product or names
one. What was kept is method: prompt element ordering, the weight lighting
carries, describing positively instead of excluding, giving each reference one
job, brief triage and the recurring contradictions, the action budget, shot
ordering, the continuity contract, keyframe and continuation planning, audio
layering, and the rule that exactness belongs in post. A vendor-branded example
prompt was not carried across. Every body was written from scratch into the
Clawboo SOUL, IDENTITY and TOOLS document set, frontmatter was replaced with
structured catalog fields, and every description was newly written. This pack
ships no teams, because two agents in one narrow discipline do not make one.
Skill declarations, categories, tags, colours and emoji are Clawboo's.
