**No code and no text was copied.** The upstream project is a command-line
toolchain: the large majority of its files are source code, and its documents
are generated from templates that invoke its own binaries and local state paths.
None of that can be carried into a marketplace pack, and copying it would be
redistribution rather than adaptation. What was adapted is the idea layer only:
the one-person role chain, the order in which those roles hand work to each
other, and the editorial stance that every handoff is a written artifact rather
than a conversation. Every agent body, team narrative, routing edge, rubric,
severity scale and checklist in this pack was written from scratch by Clawboo at
Clawboo's own granularity. Upstream command names, binaries, file paths, state
directories and tool-bound roles were dropped entirely.
