**Modifications**: this pack is adapted, not verbatim. The upstream repository
carries 153 skill units. Only the 65 vendor-neutral units under `skills/production/**`
were considered; the 88 provider-reference units were excluded because they are
written against specific paid media APIs, and the repository's own evaluation
files were excluded as repository tooling. Those 65 units were then merged and
re-scoped into 12 agents: several units became one agent where they describe one
person's job, and no unit was carried across as a file. Every body was rewritten
into the Clawboo SOUL, IDENTITY and TOOLS document set in the maintainers' own
words. Upstream frontmatter was replaced with structured catalog fields, every
description was written fresh, provider names, tool branding, bundled scripts,
prompt templates and source ledgers were removed, and no executable file ships
in this pack. The four teams, their rosters, the leader choice, the workflow
narratives and every routing edge are original to Clawboo, as are the nine pack
skills, the categories, tags, colours and emoji.
