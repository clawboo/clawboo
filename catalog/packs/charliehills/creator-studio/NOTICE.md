**Modifications**: this pack is adapted, not verbatim. The upstream repository
ships seventeen short skill documents, a shell validation script and reference
assets. The script and the assets were not imported; a Clawboo pack carries
Markdown and JSON only. The upstream documents are small, between roughly two
and eleven kilobytes, and are written as step-by-step interactive scripts. They
were reworked into twelve Clawboo agents with the SOUL, IDENTITY and TOOLS
document set, expanded with the craft reasoning the short originals leave
implicit.

Material specific to the upstream author was removed rather than generalised.
That includes one skill built entirely around a named individual and their
colleagues, that individual's own published engagement benchmarks, and the
instruction to score a stranger's draft against them. Named third-party paid
services, required API-key environment variables, a named commercial data
scraper, named image-generation products and a named creator's proprietary
planning framework were all removed; the underlying techniques are described
generically so the agents work with whatever tooling a user already has. Every
description was rewritten, and unsourced performance figures were either dropped
or reframed as assumptions to check against an account's own analytics. The
three teams, their rosters, the leader choices, the workflow narratives and every
routing edge were written by the Clawboo maintainers, as were the skill
assignments, categories, tags, colours and emoji.
