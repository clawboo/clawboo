**Modifications**: this pack is adapted, not verbatim. The upstream repository
ships twenty-one skill documents, six agent definitions, reference files and a
set of Python extraction scripts. None of the scripts, installers or packaging
files were imported; a Clawboo pack carries Markdown and JSON only. The six
upstream agent definitions and the platform reference material were reworked
into eight Clawboo agents with the SOUL, IDENTITY and TOOLS document set.
Frontmatter was replaced with structured catalog fields. Every description was
rewritten. Upstream command syntax, flag names, sub-skill file paths, the
image-generation extension branding and the third-party stock-image search
recipe were removed. Engagement multipliers that the upstream files stated as
fact are either dropped or reframed as assumptions to check against an account's
own analytics. The two teams, their rosters, the leader choice, the workflow
narratives and every routing edge were written by the Clawboo maintainers, as
were the skill assignments, categories, tags, colours and emoji.
