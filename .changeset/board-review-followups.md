Fix several small issues found in review. A Stop in Boo Zero's chat now holds even when you send another message while its reply is still handing work out. An inch mark such as `5"` no longer stops a real hand-off from starting, and a hand-off shown in quotes or code is left as written. More wordings of a context-window overflow get the right advice. Pause cards name the button they show, and a reopened wake card alerts again. A failed check of an old agent at startup is no longer counted as reaped on every start.
