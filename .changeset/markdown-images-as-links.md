Images in an agent's markdown no longer load on their own. An image in chat, a task's report or its comments used to load from wherever its address pointed as soon as it was shown, so an agent steered by something it read could send data out in that address. It now shows as a link named after its alt text that opens only when you click it; an address that is not a web or same-site one is only named.
