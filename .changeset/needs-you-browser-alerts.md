Clawboo can send a browser notification when something new needs you while its tab is in the background: a task whose run failed or stopped responding, one an agent marked blocked, work that did not pass its checks, and an agent waiting for your approval. The board offers it once, with an explanation, and asks the browser only when you click Turn on. Several arrivals at once make one alert, and a click opens the task or Needs you. Turn it off or send a test alert in Settings, under System. The Clawboo desktop app keeps using its own notifications. The task drawer is quieter too: an empty Activity box is one line, the Live mark no longer covers the first event, and opening a task without a worktree no longer logs an error. Panel titles and section labels now use the type scale and the muted text colour.
