Your reply on a task now reaches its agent whatever the task's status, and you can see where it went. A reply to a task that is waiting on you, or waiting in To do, starts the agent on it again, so answering a blocker no longer needs a second click on Retry; quick replies start one run between them. A reply to a running task goes into the run, and one to a task in review waits for the agent to read after the check. A task moved back to To do still reaches the agent it belongs to. A finished task cannot run again, so the reply is not sent and the note under it offers to send it as a follow-up task for the same agent. The board's task drawer now has a reply box, and both the drawer and the chat's task card show under each reply where it went. The chat card's Send and retry button is gone, since a reply now does both.
