Budgets in Settings > Insights > Governance are now set by name. Pick agent, team or mission, then choose from a list you can search: agents show their team, so two agents with the same name stay apart, teams leave out archived ones, and missions list the top-level board tasks, newest first. You no longer need to look up an id first. Each budget shows the agent, team or task name, and shows the id once that agent, team or task is gone. The form no longer offers tenant, since nothing charges a tenant budget; any tenant budget you already have still shows.
