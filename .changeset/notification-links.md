In the Clawboo desktop app, clicking a notification now opens what it is about: the task's drawer, or **Needs you** with the approval's card brought into view and ringed for a moment, instead of only bringing the window forward. Any app that shows the dashboard in its own window can do the same through `onOpenTarget` on the object it gives the page. See **Open the dashboard from a notification** on the deployment page.
