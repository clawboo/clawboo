New connector: **Cua Driver** (category **Desktop**, Linux only) uses the apps on an agent's own screen through Clawboo's tool server: it lists windows, clicks, types and reads each app's accessibility tree. It runs only when agents run as their own OS user (`CLAWBOO_AGENT_USER`), like control links: it types into the agent's browser, which otherwise runs as you. Without it, agents still get their screen, the live view and their browser tools. Install it from an agent's **Screen** view, connect it, and give it to the agents that need it; it is not given to every agent. Each agent gets its own Cua Driver process on that agent's own screen, as the agent user when agents run as their own OS user, with a home folder of its own and the screen's own session bus, never your desktop session's. It runs only from Clawboo's own install, with its telemetry and update check turned off. A call that names no agent, or for an agent with no screen of its own, is refused rather than run against another screen, and while a person has taken over the screen its calls wait like the browser's. The tools that run code, start or stop programs or a browser of its own, install things, change its settings or move files between the computer and a website need Admin access, and the arguments with which it writes a file wherever they point are refused. **Connect** says when a program Clawboo installs itself is not installed, or not for this platform.
