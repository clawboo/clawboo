New task on the board now starts with one field: write what should get done and press Enter. It suggests who should do it by matching your words to each agent's name and the role in its SOUL.md, and otherwise suggests the agent you last gave a task to, then the team lead. A note beside the agent says why, and you can pick someone else; picking an agent also picks its team, so with the board showing all teams you no longer choose a team first. More options opens the full form with Team, Agent and Details.
