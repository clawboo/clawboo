'clawboo': minor

The Inbox has a **Mine** tab: the tasks assigned to you, the same ones as the board's **Mine** filter, newest change first. **Retry** and **Assign** now record who asked on the note they leave, behind a sign-in proxy. A run your comment, answer or **Reopen** starts no longer shows its task as unread for you when the card moves, even some time later, such as when a hold lifts, while anything you had not read stays unread and what the agent does next is news as usual. A work check that fails after a comment's turn counts only its failures, so it says "failed once" rather than "failed 2 times". A run labelled `openclaw` by anything other than the team engine is no longer treated as the engine's: archiving a room leaves it alone, a restart does not time it out, and its delegator hears how it ended. An engine run recorded before this update still reads as the engine's. A Gateway rate limit whose message says "too many tokens" no longer gets the context-window advice, and is filed as a rate limit, as is that phrase with nothing to say which limit it means. The startup warning about Hermes's security scanner no longer appears in a Hermes agent's reply.
