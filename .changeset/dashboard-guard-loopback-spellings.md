Close gaps in the guard that keeps agents' browsers off the Clawboo dashboard. With `HOST` set to anything but `127.0.0.1`, such as a loopback alias like `127.0.0.2` or a LAN address, neither browser connector blocked the dashboard at that address, and the broker check let calls naming a LAN address through. Both browsers and the broker check now block the address set in `HOST`, and Playwright also blocks every `127.x.x.x` address on the dashboard's port. Both also block the port on every name under `.localhost`, which Chrome sends to this computer without asking DNS, on IPv4-mapped addresses such as `[::ffff:127.0.0.1]`, and on `[::]`. The broker check that refuses a connector call naming the dashboard now reads the address the way a URL parser does, so a percent-escaped or full-width spelling of `localhost` or `127.0.0.1`, a leading zero on the port, or a tab or line break inside the address no longer slips past it. That check is the only one between the dashboard and a connector that fetches URLs itself.
